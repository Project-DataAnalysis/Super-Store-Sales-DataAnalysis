# 🛒 Super Store Sales Dashboard (Power BI)

## 📌 Brief One Line Summary  
An interactive Power BI dashboard to analyze and forecast retail superstore sales across products, regions, and time periods.

## 📝 Overview  
This project showcases an end-to-end data analytics workflow - from data preparation to interactive visualization - to provide actionable insights for a retail superstore. It includes sales performance, profit tracking, and a 15-day forecast for better decision-making.

## ❓ Problem Statement  
Retail decision-makers need a consolidated view of sales, profit, and shipment metrics across multiple product categories, states, and customer segments to plan inventory and marketing efforts. The challenge is to provide an easy-to-use, interactive tool that delivers these insights quickly.

## 📂 Dataset  
The dataset includes twoyears(2019–2020) transactional data with the following attributes:
- Order Date, Ship Date, State, Region, Segment  
- Product Category and Sub-Category  
- Sales, Profit, Quantity, Ship Mode, and Payment Mode  

## 🛠️ Tools and Technologies  
- **Power BI Desktop** for data visualization and dashboard design  
- **DAX** for calculated measures and KPIs  
- **Data Modeling** for relationships between tables  

## 🔍 Methods  
1. Imported and cleaned raw data in Power BI.  
2. Built data model relationships for seamless analysis.  
3. Created KPIs for Sales, Profit, Quantity, and Ship Days.  
4. Designed visuals segmented by Category, Sub-Category, Segment, Region, and State.  
5. Implemented a 15-day sales forecast using time-series analysis.  
6. Enhanced interactivity with slicers, filters, and drill-through features.

## 📊 Key Insights  
- Identified top-performing product categories and sub-categories.  
- Uncovered regional differences in sales and profit margins.  
- Showed seasonal trends in monthly sales and profit.  
- Forecasted sales for the next 15 days to aid inventory planning.

## 🚀 How to Run This Project?  
1. Download the `.pbix` file from this repository.  
2. Open it in **Power BI Desktop**.  
3. Refresh the data (if needed) and interact with the visuals.  

## 📈 Results & Conclusion  
The dashboard provides a one-stop view of sales and profit metrics across multiple dimensions. It empowers stakeholders to make data-driven decisions on product strategy, regional focus, and inventory management.
